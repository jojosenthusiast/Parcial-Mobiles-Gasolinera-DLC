# Evidencia E23 — Resiliencia y operaciones

**Fecha:** 2026-10-08

## Implementación

- Las mutaciones usan identificador de comando, hash del contenido y transacciones. La outbox y los workers usan leases y reintentos.
- La app conserva tokens remotos en Keychain y datos pendientes en almacenamiento local protegido. Las operaciones de resultado incierto quedan pendientes de reconciliación.
- La renovación simultánea del refresh token móvil comparte una petición.
- La API registra método, ruta, estado, clase de excepción y referencia de correlación. No incluye cuerpos, credenciales, tokens ni mensajes de excepción.
- Los scripts generan respaldos AES-256-GCM, aplican retención y restauran en una base aislada con verificaciones de integridad.
- Los adaptadores de surtidores y pagos continúan en modo manual/simulado; no hay protocolo ni credenciales de los equipos reales.

## Verificación ejecutada

- PostgreSQL 16.15: migraciones 0001–0083 en una base vacía y segunda ejecución idempotente.
- 40/40 pruebas SQL de dominio, consistencia de tenant, operaciones, permisos y reportes.
- API con rol de runtime restringido: 3/3 pruebas HTTP. Health 200, readiness 200 con base conectada y `/auth/me` sin sesión 401 con correlación preservada.
- Backup AES-256-GCM con `pg_dump` y restore aislado con `pg_restore` 16.15: PASS. Las verificaciones de estructura e integridad terminaron; no se midieron RPO/RTO ni se restauraron datos operativos.
- Supabase DLC: ledger de la aplicación con 83 filas y checksums coincidentes, 135 tablas públicas con RLS, 0 funciones públicas ejecutables por `anon`, `authenticated` o `service_role`. Asesor de seguridad: sin hallazgos. Solo existe `dlc_api_runtime` NOLOGIN; falta el login de servicio y su secreto.

## Hallazgos pendientes

- Los privilegios por defecto de `supabase_admin` aún permiten EXECUTE a `anon`, `authenticated` y `service_role` para funciones futuras en `public`. Las funciones actuales quedaron revocadas y ninguna es ejecutable por roles cliente. El usuario de conexión MCP es `postgres`, no es superusuario ni miembro de `supabase_admin`; la revocación futura falló por falta de privilegio y no se incluyó una migración que no pueda instalarse. Para cerrar este punto se necesita una sesión con privilegios de `supabase_admin`.
- El asesor de rendimiento reporta INFO: 327 claves foráneas sin índice de cobertura y 33 índices sin uso registrado. No hay consultas ni carga operativa representativa; no se agregaron ni quitaron índices de forma masiva. Revisar con planes de consulta y métricas de uso.
- Faltan `promtool`, scrape privado y receptor para validar alertas en ejecución.
- Falta repetir backup/restore contra QA con datos operativos, medir RPO/RTO y probar fallas/concurrencia.
- Xcode/Simulator y equipos, terminales, sensores y credenciales de proveedores no están disponibles.
