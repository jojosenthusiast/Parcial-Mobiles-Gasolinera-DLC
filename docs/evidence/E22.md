# Evidencia E22 — Panel web

**Fecha:** 2026-10-08

## Implementación verificada

- El panel consulta la API con capacidades del perfil, mantiene sucursal, módulo, periodo y filtros en la URL, y permite volver a vistas anteriores.
- Los módulos de sucursales, equipos, cortes, inventario, incidencias, compras, precios, caja, tienda, gastos, personal, usuarios, mantenimiento y reportes cuentan con listas filtrables y navegación a detalle según el permiso disponible.
- La ficha de bomba registra línea base o lectura acumulada por boquilla; el backend valida versión, permisos y trazabilidad. El flujo de cortes permite captura, conciliación, revisión y cierre.
- Las operaciones web envían sus cambios a los endpoints de la API; el backend vuelve a validar el alcance y las capacidades.
- Los errores web presentan código HTTP y referencia de correlación. La consola registra solo evento, código, estado HTTP y referencia; no registra mensajes, cuerpo, credenciales ni tokens.

## Verificación local

- `node --check web/server.mjs`, `node --check web/public/app.js` y `pnpm test:web` — PASS.
- `pnpm test:unit` — PASS; los servicios de cortes, inventario, personal, compras, caja, ventas y tienda corren contra las pruebas locales.
- `pnpm test:contract` — PASS; incluye el contrato de navegación, permisos, filtros, accesibilidad estructural y errores rastreables.
- `pnpm build`, `pnpm typecheck` y `pnpm lint` — PASS.
